# 系统时钟风格界面调整

日期：2026-10-02。界面改动随 v2.0 发布；原 v1.9 APK 保留为历史版本。本文件记录界面设计及前期预览，正式版本验证见 [2.0 验证说明](release-v2.0-validation.md)。

## 界面与操作

- 首页以大字显示下一个闹钟及距离响铃的时间，下面是按时间排序的简洁列表；右下角添加按钮始终可用。
- 列表保留时间、名称、重复日期、振动说明和启停开关；振动设置、跳过下一次响铃移到编辑页。待响稍后提醒仍显示时间及取消入口。
- 右上角设置包含闹钟音量、权限检查、测试响铃和检查更新。权限齐全时首页没有提示；缺少关键权限时显示一条可点击提示，不在打开首页时自动弹请求。
- 编辑页使用统一的深色分组、滚轮时间选择和声音选项；保存、取消固定在底部，重复、铃声、振动、渐强、稍后提醒和响铃时长保持可用。
- 响铃页统一深色背景、大时间和大触控按钮，保留多闹钟实时状态、稍后提醒失败时继续响铃及锁屏操作。

## 无备份

按用户要求移除备份功能：删除手动导入/导出、上一份闹钟的自动备份和损坏数据回退；访问数据时清理旧备份键。关闭系统云备份及设备迁移备份，补充 Android 12 及以上的数据排除规则。

现有闹钟仍正常保存在本机。设备加密存储、旧版闹钟升级迁移、编号分配、稍后提醒状态及同步写入保留。

## 验证方法

使用已有 JUnit/Robolectric 测试，无新增运行时依赖。界面测试覆盖设置入口、条件权限提示、权限设置跳转、添加、编辑与开关保存；存储测试覆盖正常保存、旧备份清理、损坏数据不恢复旧闹钟和系统备份关闭。

原生绘制预览使用实际 Android Views，包含正常页面、空状态、权限缺失、编辑选项及窄屏大字体。窄屏为 320×640 dp，字体为 1.5 倍。预览不包含真实设备的系统导航栏，也不能验证厂商系统或实际出声。

```powershell
$env:JAVA_HOME = 'D:\Android\Android Studio\jbr'
$env:SIMPLE_ALARM_UI_PREVIEW = '1'
.\gradlew.bat --offline :app:assembleRelease :app:lintRelease :app:testDebugUnitTest
```

生成的预览位于 `build/ui-preview/`。不设置环境变量时只跳过原生绘制预览用例，功能测试仍执行。

预览安装包沿用 v1.9 的版本号和发布签名，仅用于本地验证界面；不覆盖仓库中已有的正式 APK 或线上更新清单。
