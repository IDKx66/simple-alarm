# 简洁闹钟（Android）

一个无广告的原生安卓闹钟应用。当前版本为 1.9；除检查更新外，其余功能可离线使用。

## 功能

- 添加、编辑、启用和停用闹钟
- 支持仅一次、工作日、每天快捷选择或自选星期重复
- 锁屏响铃、系统闹钟声音与震动
- 自定义铃声、独立震动开关和 30 秒渐强音量
- 可选 5/10/20 分钟响铃时长
- 可选 5/10/15 分钟稍后提醒及次数上限
- 大按钮停止，独立稍后提醒；响铃页振动开关仅影响本次
- 首页显示距离下次响铃的时间，支持跳过下一次重复闹钟
- 权限检查和立即测试响铃
- HTTPS 检查更新、下载新版 APK 并打开系统安装界面
- 更新包 SHA-256 完整性校验，内置官方更新地址
- 闹钟数据自动保留上一份有效备份，支持导出和恢复
- 检查精确闹钟、通知和锁屏全屏提醒权限
- 手机重启或系统时间变化后自动恢复闹钟
- 使用 Android 闹钟时钟 API 调度精确闹钟；部分厂商系统仍可能限制后台运行，建议按设备提示设置自启动和电池策略
- 长按闹钟即可删除

## 安装与使用

1. 从[官方下载页](https://simple-alarm-updates.idkx66.chatgpt.site)下载 v1.9，或在安卓手机上打开 `releases/SimpleAlarm-v1.9.apk`，并允许安装此来源的应用。
2. 首次打开时允许通知和“闹钟与提醒”权限；也可通过首页“权限检查”查看或补充设置。
3. vivo 手机建议在系统设置中允许该应用自启动，并将电池用量设为“不限制”。
4. 添加一个两分钟后的测试闹钟，锁屏验证响铃是否正常。

> 1.9 版已验证与 1.8 版签名证书一致，可以覆盖安装并保留已有闹钟。升级后建议打开一次应用，再验证锁屏响铃和重启恢复。

## 配置检查更新

应用已内置更新清单地址。开发者也可重新设置地址，清单格式见项目根目录的 `update-example.json`：

```json
{"versionCode":10,"versionName":"1.9","apkUrl":"https://simple-alarm-updates.idkx66.chatgpt.site/SimpleAlarm-1.9.apk","sha256":"b1032e923fae47029a493644f2a84cd43e8c6b1d8e59fd906c2fe039921d8a2f","notes":"修复重启后稍后提醒恢复、旧提醒误触发和多闹钟合并状态；改进通知权限检查。"}
```

把清单和新版 APK 放到可公开下载的 HTTPS 地址即可。应用不能绕过安卓系统确认静默安装，这是系统安全限制。

最低支持 Android 8.0（API 26），目标版本 Android 15（API 35）。

项目的 `AndroidManifest.xml` 也显式声明了 API 26/35，以保证使用 Gradle或直接使用 Android 构建工具打包时，生成的 APK 都带有正确的系统兼容信息。

## 1.9 改动

- 重启、应用更新、系统时间变化及精确闹钟权限恢复后，重新安排普通闹钟和稍后提醒；保存的数据迁移到解锁前可读取的存储区域，保留备份及编号。
- 稍后提醒使用保存的触发时间校验，已取消或已处理的旧提醒不会重新响铃；恢复过期提醒时保留原来的触发时间。
- 多个闹钟合并响铃时，页面、通知和操作同步当前状态；稍后提醒调度失败的闹钟继续响铃，后来加入的闹钟可获得完整响铃时长。
- 权限检查可识别应用通知总开关和闹钟通知渠道被关闭，并打开对应设置页。
- 一次性闹钟进入稍后提醒后，首页显示待响时间并提供取消入口；相同时间的闹钟不可重复保存或从备份导入。
- 编辑页直接显示重复方式；展开响铃通知可使用稍后提醒操作（实际按钮位置由 Android 系统决定）。
- 增加 28 项自动回归测试；正式包构建、签名、SDK、包对齐和静态检查已通过。真机锁屏、重启后首次解锁前响铃及系统投递延迟仍需验证，详见[可靠性验证说明](docs/reliability-validation.md)。

## 1.8 改动

- 重复日期增加“仅一次”“工作日”“每天”快捷选择。
- 首页增加权限检查和备份恢复入口。
- 多个闹钟同时响铃时显示数量，并改进稍后提醒上限反馈。
- 延续 v1.7 的更新包 SHA-256 校验；本版编译、签名和包结构已验证。用户已确认覆盖安装及首次锁屏响铃成功，重启恢复尚未验证。

历史问题：v1.8 中一次性闹钟进入稍后提醒后，首页可能显示没有启用的闹钟；v1.9 已修复显示并加入计时日志。用户反馈的十几秒稍后提醒延迟仍需在设备上核对。

## 1.7 改动

- 修复更新下载完成后不进入系统安装界面的问题，并处理安装来源权限。
- 稍后提醒达到上限后隐藏入口；调度失败时保持响铃并提示。
- 同一分钟触发多个闹钟时合并处理，避免状态互相覆盖。
- 自定义铃声失效时自动使用系统铃声。
- 权限页读取锁屏全屏提醒的真实状态。
- 更新包下载后校验 SHA-256，校验失败则删除错误文件。
- 内置官方更新地址，检查更新不再要求首次手动填写。
- 闹钟数据损坏时读取上一份有效备份，并支持导出和恢复。

## 本版说明

深色圆角卡片与滚轮编辑页；保留主界面振动开关；增加铃声试听、恢复默认、音量调整和低音量提示；显示下次响铃日期；校验更新后提供安装通知与返回应用继续安装入口；修正备份保护和恢复后的编号分配。

重复模式支持“仅一次”“工作日”“每天”快捷选择，也可自选星期。跳过下一次仅适用于重复闹钟；一次性闹钟可直接停用。30 秒渐强需要 Android 9（API 28）及以上，Android 8 不提供渐强。

首页提供权限检查和备份恢复快捷入口；点击闹钟卡片编辑、长按删除。响铃页在达到稍后提醒次数上限时会显示对应状态。更新下载后点击安装通知，或返回应用继续安装。

新界面尚未完成真机或模拟器视觉验证；本版本不包含世界时钟、秒表或计时器。

## 排查稍后提醒延迟

使用 `adb logcat -s SimpleAlarmTiming:I` 查看 `scheduled snooze`、`received snooze` 和 `ringtone play`。比较 `due`、`received`、`playAt`：`lateMs` 包含系统投递及应用处理时间，`appMs` 是广播收到至发出铃声播放请求的时间。播放请求时间不等于扬声器实际出声时间。
